1 Launching via Google Colab (Recommended)

Google Colab runs entirely in your web browser. You do not need to install Python, Jupyter, or Git on your machine.

Step 1: Open the Notebook

Click the golden "Open in Google Colab" button at the top of this page or inside the GitHub repository.

⚠️ Crucial Step: Save a Copy to Google Drive
Colab initially opens in temporary "Playground" mode. To save your solutions permanently:
Click File ➔ Save a copy in Drive in the top menu. This creates a personal copy in your Google Drive.

Step 2: How to Run Code

  • Click inside any code cell to select it.
  • Press Shift + Enter to execute the active cell and advance to the next one.
  • Or click the circular ▶ Play icon on the left border of the cell.

Step 3: Solving & Testing

Each problem has two cells: your starter template and an automated test suite. Replace the pass keyword with your code and run the test cell below it:

def contains_duplicate(nums: list[int]) -> bool:
    seen = set()
    for num in nums:
        if num in seen:
            return True
        seen.add(num)
    return False

When you run the test cell and see [PASS] All tests passed!, your solution is verified!

4 Common Beginner Errors & Fixes

IndentationError

Python requires consistent 4-space indentation. Verify all lines inside def, for, and if blocks align perfectly.

IndexError: Out of Range

Occurs when arr[i] attempts to access an index beyond the array size. Always guard pointer loops: while left < right and ...

AssertionError: Test Failed

Your code returned an unexpected output for a specific edge case. Check if your solution handles empty strings or single-element lists properly.

Infinite Execution Loop

If a cell runs indefinitely without stopping, your while loop forgot to increment left += 1 or decrement right -= 1.
